# Category rules

Effort is split into categories: programming, specification, documentation,
translation, deployment and config.

This step scans the open workspace and proposes:

- **file types** the built-in rules count as *Other* (for example `*.vue`, `*.rdlc`),
- **folders** such as `docs/`, `specs/`, `infra/` or `translations/` whose files
  would move to a better category.

Tick the rules you want. Folder rules win over file-type rules.
You can edit them later in **⚙ Settings → Categories**.
