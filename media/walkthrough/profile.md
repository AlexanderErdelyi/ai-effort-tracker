# Developer profile

The tracker values AI-generated code by asking how long you would need to write it by hand.

| Level | Preset baseline |
|---|---|
| Junior | 3 lines / minute |
| Mid | 5 lines / minute |
| Senior | 8 lines / minute |

The preset only pre-fills the number. Type your own value if it fits you better.
You can also set a baseline per category (programming, docs, …) in **⚙ Settings → Profile & baselines**.
