# Restore from a backup

Use this on a new machine or after reinstalling VS Code.

- Pick a backup file created with **AI Effort Tracker: Export Full Backup…**.
- Tracking data (time, lines, credits, work items, projects), captured corrections,
  review marks, rules for Copilot and your settings come back. The GitHub token is never in a backup.
- The tracker saves a safety copy of the current data before it restores.

Starting fresh? Skip this step.
